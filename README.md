# Git & GitHub Guide for Students
# راهنمای Git و GitHub برای دانشجویان

**Project Status: Completed**

این مخزن یک مستند آموزشی کامل و عملی برای دانشجویان مبتدی نرم‌افزار است که می‌خواهند با Git و GitHub کار تیمی را یاد بگیرند. هدف این است که پس از مطالعه این راهنما، بتوانید یک پروژه را به صورت انفرادی یا گروهی مدیریت کنید، تغییرات را کنترل کنید و با اعضای تیم همکاری کنید.

## ساختار پروژه

```
GitHub-Guide/
├── README.md              ← همین فایل (معرفی پروژه و اعضای گروه)
├── basic-commands.md      ← دستورات پایه Git (init, add, commit, push, pull, clone و ...)
├── branching.md           ← شاخه‌بندی (Branch)، کار موازی و محافظت از main
├── merging.md             ← ادغام (Merge)، Fast-forward، Merge Commit و Conflict
└── collabration.md        ← همکاری تیمی روی GitHub (Issue، Pull Request، Code Review)
```

## مخاطب

دانشجویان مهندسی نرم‌افزار که تجربه کمی در کنترل نسخه و کار تیمی دارند.

## نحوه استفاده

1. از `basic-commands.md` شروع کنید.
2. سپس `branching.md` را بخوانید.
3. بعد `merging.md` را مطالعه کنید.
4. در نهایت `collabration.md` را برای کار گروهی کامل کنید.

هر بخش شامل توضیح مفهوم، مثال عملی، دستورات و نکات کاربردی است.

## فرآیند انجام تمرین

این پروژه طبق سناریوی تمرین گروهی درس مهندسی نرم‌افزار انجام شده است:

- ایجاد Repository عمومی و افزودن Collaboratorها
- ایجاد Issue برای تقسیم وظایف
- کار روی Branchهای مستقل
- Commitهای معنادار
- ایجاد Pull Request و انجام Code Review
- شبیه‌سازی و حل واقعی Merge Conflict روی فایل README.md


**نکته:** تمام فعالیت‌های اعضا (Branch، Commit، PR، Review و حل Conflict) در تاریخچه این مخزن قابل مشاهده است.
